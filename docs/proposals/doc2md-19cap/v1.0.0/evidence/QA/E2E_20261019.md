## 3. 桥接：发票 → 复核包**不存在**

代码证据（非推断）：

| 问题 | 答案 |
|---|---|
| `assemble_package` 能接受 PDF/OCR 结果吗？ | **不能**。签名要求 `DocxPackage`，否则 `E_INPUT_INVALID`；内部强制 `extract_tables(package, …)` |
| 有调用方消费 `normalise_response` 吗？ | **没有**。生产代码零引用，只有测试 |
| 断点在哪 | `adapters/paddle_structure.normalise_response()`（产出 `PaddleTableResult`，无下游） → `pipeline.assemble_package()`（只接 `DocxPackage`） |

缺的**不是一个转换层，而是三处**（QA 补充修正：不是"第二个依赖"，是第二、第三个）：

| # | 缺什么 | 触发点 | 为什么不能靠转换补齐 |
|---|---|---|---|
| 1 | `DocxPackage` 之外没有任何入口 | `pipeline.py:233-236` `isinstance` 守卫；`:243-249` 固定走 `extract_tables`，**无表格注入参数** | 入参类型本身就是契约 |
| 2 | **每张表**的 `header_rows` | `correction.py:435-447`：`header_rows_by_table.get(rebuilt_table)`，缺表即 `E_REVIEW_REQUIRED` | 逐表要求，"给个默认表头"糊不过去；来源是 `word/table_flags.py:170-173` 的原生 `w:tblHeader` |
| 3 | **`slots` 矩阵** | `pipeline._structural_evidence_ids`（`:138-194`）：payload 无 `slots` 直接 `E_INPUT_INVALID` | fail-closed 设计，不是可选项；没有 slots 连复核包都拼不出来 |

坐标（可直接引用）：

```text
pipeline.py:225        assemble_package(package: DocxPackage, ...)
pipeline.py:233-236    isinstance 守卫 -> E_INPUT_INVALID
pipeline.py:243-249    固定走 build_final_view/extract_tables/read_table_flags/read_notes
word/package.py:250    open_docx(path)：DocxPackage 的唯一来源
word/table_flags.py:170-173,196   read_table_flags -> HEADER_SOURCE_NATIVE
adapters/paddle_structure.py:286,468  normalise_response -> PaddleTableResult（零消费者）
```

**结论**：`header_rows` 与 `slots` 都属于"要在 OCR 侧新建一份原生标记的等价物"，不是转换层能补齐的。
