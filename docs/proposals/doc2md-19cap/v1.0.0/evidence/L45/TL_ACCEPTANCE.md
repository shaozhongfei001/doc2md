# L45 验收记录（退化样本上的 score → 行正确率曲线）

- 入口：`loop-entry/L45` = `a572ade`
- 结果：`results.json`（16 源 × 10 变体 = **160 页变体**，8827 行）
- **状态：`CODE_MERGED`；结论是"0.6 偏低"，但**不改产品常数**（等人工标注印证）**

## 1. 方法

| 项 | 做法 |
|---|---|
| 源 | 发票目录 16 张（8 个有文本层 PDF、4 个扫描 PDF、4 张图片） |
| 退化 | clean / blur1-4 / down40-70 / contrast / mix，共 10 档 |
| 参照 | **同一页未退化时的 OCR 文本**（不是 PDF 文本层，也不是人工标注） |
| 判定 | 每行与参照行做字符相似度：≥0.9 判"对"，0.5–0.9 判"错"，<0.5 记"无法比对" |

## 3. 阈值对比

| 阈值 | 保留行 | 错行 | 错误率 | 相对 0.6 少留 |
|---|---|---|---|---|
| **0.6（现状）** | 8561 | 383 | **4.47%** | — |
| 0.8 | 8445 | 307 | 3.64% | 1.4% |
| 0.9 | 8255 | 222 | **2.69%** | 3.6% |
| 0.95 | 7876 | 132 | **1.68%** | 8.0% |

读法：

- **低于 0.9 的行，精度最高只有 0.76**（0.9–0.95 桶），更低的桶在 0.29–0.55；
- **高于 0.95 的行，精度 0.983**；
- 把阈值从 0.6 提到 0.9，只多丢 3.6% 的行，却把错误率从 4.47% 降到 2.69%（**错行减少 42%**）。

即：**0.6 落在"几乎全是错行"的区间里**，把它当复核触发线，等于让一半左右的低分噪声直接进入复核，
而真正的分界在 **0.9 附近**。

## 4. 必须写清的三个局限

1. **参照是机器文本**：未退化 OCR 本身可能错，它给出的错误率是**相对量**，不是绝对准确率；
2. **"无法比对"被排除**：低分桶可判定率只有 0.19–0.47，**未能比对的多半是更糟的行**，
   所以低分桶的真实精度只会更低（结论方向不受影响，幅度会变）；
3. **退化是我造的**：blur/downsample 与真实扫描的噪点、印章、折痕不同，
   不能替代真实低质量样本（`L45-LIM-01`）。
