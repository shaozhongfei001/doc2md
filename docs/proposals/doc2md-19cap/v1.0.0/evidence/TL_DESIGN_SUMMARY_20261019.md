## 2. 架构（数据流）

```text
PDF/图片
  │  PaddleOCR（独立 venv，GPU）
  ▼
文字 + 坐标 + 逐行分数
  │  adapters/paddle_structure（几何校验：box ↔ HTML 网格逐格比对）
  ▼
表格网格 / cells（row, col, rowspan, colspan）
  │  tables/semantics（表头路径）· tables/notes（脚注绑定）
  ▼
复核包（omission ⊆ evidence）
  │  人工复核
  ▼
generation（原子提交，CAS 换指针）
  │  订正
  ▼
correction（只重建受影响表） → 新 generation
  │  产出"应作废证据清单"
  ▼
revocation（人工触发） → 标记流水（append-only，双时间戳）
  └─ 可恢复：再追加一条 RESTORE，**不删历史**
```

三条贯穿性原则：

1. **不猜**：表头带不按加粗猜、几何不一致不按最近格配、无记录不猜"作废前状态"；
2. **不静默**：孤儿脚注、重复 id、未归因证据、补丁残缺，一律变成可见的 issue/报告；
3. **单一事实源**：状态由流水 fold 得出，不另存"当前状态"字段。

## 3. 关键设计决策（及反对的选项）

| 决策 | 选了 | 没选 | 理由 |
|---|---|---|---|
| 证据作废怎么存 | 标记流水（append-only） | ①新 generation ②独立 registry | ①贴标签不该抬版本号；②两本账迟早对不上（L23–L27 的教训） |
| 作废能不能撤 | 能，追加 RESTORE | 不可撤销 | 误作废的代价是证据永久不可用 |
| reviewer 校验 | 形式 + 可配置策略 | 只查非空 / 接认证 | 形式能挡占位串；认证缺外部系统 |
| 表格 box 绑定 | 几何证明 | 按列表下标 | 下标不是身份 |
| 阈值 | 不动（仍 0.6，候选 0.9） | 直接改 0.9 | 参照是机器文本，不能据此改常数 |
| 无表文档有脚注 | 拒绝 | 静默出包 | 少脚注却看起来完整更危险 |

1. 不声称端到端生产可用（无真实 OCR 环境和真实语料）；
2. 不声称表格解析在真实票据上可用（真实页 0 样本）；

4. 不声称阈值已校准（0.9 只是候选）；
5. 不声称 reviewer 身份可信（只校验形式）；
6. 不声称作废自动发生（需人工触发）；
7. 不声称跨进程并发安全（单机 flock，未并入 artifact_store 锁）；
8. 不声称 MySQL 131 例已跑（`NOT_EXECUTED`）；
