# Owner 决策记录（2026-10-18）

本文件只记录**判定权在 Owner** 的决定，以及它们改变了什么。
技术实现细节进各 Loop 证据，不写这里。

## D1 · `reviewer` 合法性 → 采用 A：格式 + 白名单

| 项 | 内容 |
|---|---|
| 问题 | `reviewer="---"` 被接受并写进 `audit.reviewer`（`L31-FIND-02`） |
| 决定 | **定义合法主体形式（工号/域账号），非白名单一律拒** |
| 未采用 | B 绑定认证上下文（缺认证系统）；C 保持现状（审计字段存在但不可信） |
| 后果 | 现有以 `---` 之类占位串提交的记录将**不可再提交**；已产生的历史记录不回改 |
| 待补 | 白名单来源与格式（工号正则 / 域账号域），由本决定催生的 Loop 里给出候选实现与用例 |

## D2 · 证据作废的写权 → 采用 B：人工触发 + 留痕

| 项 | 内容 |
|---|---|
| 问题 | L35 只产出"应作废清单"，仓内**无消费方** |
| 决定 | **提供 writer，由复核者人工触发，作废动作必须留痕** |
| 未采用 | A 只算不写（现状，能力受限）；C 自动作废（一次误订正会连带废掉证据） |
| 后果 | "纠错后证据会被作废"以后可以写，但**必须同时写"需人工触发"** |
| 待补 | 作废的幂等语义（`L37-OBS-01` 重复 id）、作废失败的可见性 |

## D3 · 数字估读 → 维持 A：继续禁用

| 项 | 内容 |
|---|---|
| 问题 | `OI05`：是否允许单列 `estimated_value` |
| 决定 | **维持禁用**；精确标签 / 原表 / 定性趋势照常 |
| 理由 | 一旦允许，必须回答"估算值能否参与合计"——比字段本身难十倍 |
| 后果 | `PI-F05-04` 数值分支保持不可用，相关验收项不关闭 |

## D7 · OI03 部署方式 → PaddleOCR 本机 GPU，不替换模型

| 项 | 内容 |
|---|---|
| 决定 | 保留 PaddleOCR，本机 GPU 部署；不使用其他 OCR/检测模型替代 |
| 已执行 | paddlepaddle-gpu 3.3.1 (cu118) + paddleocr 3.7.0 + paddlex[ocr] 3.7.2，独立 venv |
| 实测 | 文本 20/20、0.31 s/页；表格 20 个 cell 几何、5.09 s/页 |
| 说明 | Ollama 已卸载；它本就无法承载 PaddleOCR（非 GGUF），卸载不影响本项目能力 |
| 证据 | `evidence/OI03_PADDLE_DEPLOY.md` |

## D8 · OI04 语料授权 → 本机资料均可用于样本与 Gold

| 项 | 内容 |
|---|---|
| 决定 | 本机现有资料均可用于构造样本与人工标注（Gold） |
| 限制 | **仅限本机资料**；不得引入外部数据；标注人=Owner 或 Owner 指定 |
| 后果 | 可以开始真实语料上的精度与阈值校准，但"真实银行扫描件"是否在本机仍需盘点 |
