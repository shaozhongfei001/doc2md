- 清单：`manifest.json`（每文件 sha256、页数、文本层字符数、分类、用途）

## 1. 为什么原始文件不进仓库

发票是**报销凭证**，含公司名、金额、税号。把它们复制进 git 等于把凭证永久写进版本历史。

所以本目录只存三样东西：

| 存 | 不存 |
|---|---|
| 清单 + sha256（身份可核） | 原始 PDF/图片 |
| 选样标准与用途 | 渲染出的页面图 |
| 复现命令 | 任何 OCR 全文（含金额） |

**要复核就按清单里的路径去原目录取，用 sha256 确认是同一份。**

## 3. 入选标准（"干净"的定义）

一份文件进入样本集，必须同时满足：

1. **可复现**：路径固定、sha256 固定，任何人取到的是同一份；
2. **可归因**：能说清它验证什么能力（文本层→弱 Gold；扫描→鲁棒性）；
3. **不污染产品代码**：样本不参与 `pytest` 默认路径，跑测试不需要它。

不满足第 3 条就不进——否则"测试通过"会依赖某台机器上的私人目录。

## 4. 三类用途（各自能证明什么）

| 用途 | 用哪类 | 能证明 | 不能证明 |
|---|---|---|---|
| **弱 Gold 对齐** | `text_layer_pdf`（8） | OCR 输出与出版方文本层的重合度 | 绝对准确率；文本层本身不完整（L44 已证） |
| **版面/表格鲁棒性** | `scan_only_pdf`（4）+ `photo`（4） | 真实噪声、倾斜、拍照畸变下的表格与文字检出 | 结构正确率（无 Gold） |
| **分数-正确率** | 全部 + 退化（`L45/sweep.py`） | 低分是否意味着更可能错 | 真实扫描缺陷的分布 |

**共同的不能**：这 16 份不是银行票据，结论不能外推到银行正式凭证。

## 5. 建议的划分（给 QA 用）

| 集合 | 内容 | 用途 |
|---|---|---|
| `calibration` | 8 个 `text_layer_pdf` | 阈值/对齐的调参 |
| `holdout` | 4 个 `scan_only_pdf` + 4 张 `photo` | 只测不调，防止调参过拟合 |
| `degraded` | 由 `L45/sweep.py` 从任一页生成 | 低分样本，按需重建，不落库 |

划分原则只有一条：**调参用过的样本，不能同时用来报成绩**。
