- 结论：**`NOT_CONNECTED`**。本项不产生"已联调/已切换"结论。

## 2. 本包能证明的与不能证明的

**能证明**（合成/本地）：

- `LOCAL_READY` 与 `ACTIVE` 分离：缺任一必需 consumer 的真实 ACK，永远停在 `LOCAL_READY`；
- 模拟 ACK（`status="SIMULATED"`）**不会**被接受为 ACK；
- 目标 generation 不匹配的 ACK 被拒（消费者还在读旧版）；
- 路由切换是指针 CAS，并发不匹配返回 `E_VERSION_CONFLICT`；
- 回退只改指定 scope 的读指针，`access_ledger` 与 `tombstones` 原样保留；
- 回退目标若含已撤权内容 → `E_SCOPE_DENIED`（撤权优先于任何回退目标）。

**不能证明**：

- 任何真实切换成功率、时延、消费者兼容性；
- 银行双人审批路径（`BANK_APPROVED` 在本环境不可达，这是设计行为）；
- 旧 FULLTEXT/向量索引的真实一致性。

## 3. 联调前置条件（缺一不可）

1. 路由控制与 ACK 接口，含"消费版本"字段；
2. 银行认证上下文（审批人身份来源）；
3. 源端完整枚举能力（用于对账分母）；
4. 可回滚窗口与撤权事件通道。

四项未到齐前，`release` 只能停留在 `LOCAL_READY`，这是**正确状态**，不是缺陷。
